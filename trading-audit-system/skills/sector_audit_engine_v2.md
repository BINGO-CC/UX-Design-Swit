## 🤖 协议 -1：自动数据拉取协议 (Auto Data Fetcher) 【v2.1+ 新增】

> **设计原则：** 数值型板块数据走 API 自动拉取，趋势形态走视觉截图。双通道互为校验。
> **共享基础设施：** 与个股审计引擎共用同一台 A股数据 MCP Server。

### -1.1 数据分层：自动拉取 vs 视觉截图

| 数据层 | 获取方式 | 具体字段 | 工具 / 数据源 |
|---|---|---|---|
| **板块行情层** | 🤖 API 自动拉取 | 板块涨跌幅、成交额(近5日)、板块指数价/MA10/MA20、涨停家数 | AKShare 板块接口 |
| **Ratio 计算层** | 🤖 API 自动拉取 | 板块当日成交额、全市场当日成交额 → 自动计算 Ratio | AKShare |
| **共振度层** | 🤖 API 自动拉取 | 板块成分股列表、各成分股现价 vs MA20 → 自动计算共振度 | AKShare |
| **龙头识别层** | 🤖 API 自动拉取 | 板块内涨幅前5、换手率、近5日是否创新高 → 龙头健康度判定 | AKShare |
| **大盘环境层** | 🤖 API 自动拉取 | 指数收盘价、MA60、MACD 状态 | 同个股引擎共用 |
| **板块形态层** | 👁 视觉截图（人工） | K线趋势形态、成交额柱形结构、突破/回踩图形 | 用户提供板块日K截图 |
| **个股矩阵层** | 👁 视觉截图（人工） | 板块内个股涨跌分布、涨停板高度、梯队结构 | 用户提供矩阵截图 |
| **大盘形态层** | 👁 视觉截图（人工） | 指数趋势形态、量能结构 | 用户提供指数截图 |
| **用户私有层** | ✍️ 用户手动输入 | 总资产、仓位比例、操作周期 | — |

### -1.3 MCP 工具调用规范（板块模块）

| 调用顺序 | 工具/接口 | 用途 | 失败降级策略 |
|---|---|---|---|
| ① | `sector_realtime_quote(sector_name)` | 板块涨跌幅、成交额、涨停家数 | 降级：依赖截图提取 |
| ② | `sector_ratio_calc(sector_name)` | 计算 Ratio（板块成交额/全市场） | 降级：追问用户口述成交额 |
| ③ | `sector_resonance(sector_name)` | 共振度计算（成分股 vs MA20） | 降级：依赖矩阵截图视觉估算 |

| ⑤ | `sector_turnover_history(sector_name, days=5)` | 近 N 日板块成交额序列 | 降级：追问用户口述 |
| ⑥ | `index_realtime_quote(index_code)` | 大盘环境（共用个股引擎工具） | 降级：依赖指数截图 |

> ⚠️ **降级原则：** API 拉取失败时，自动切换为"纯截图模式"（v2.1 之前行为），并在输出顶部标注 `[⚠️ 数据源降级：部分数据来自视觉识别]`。

### -1.4 自动计算公式（原需人工的核心指标）

| 指标 | 自动计算方式 | 人工复核 |
|---|---|---|
| **Ratio** | `sector_turnover_today / market_total_turnover × 100%` | 截图成交额柱目测验证量级 |
| **共振度** | `count(成分股现价 > MA20) / count(成分股总数) × 100%` | 矩阵截图红绿比例视觉验证 |
| **龙头健康度** | `近5日最高价创新高次数 ≥ 3 且 换手率 ∈ [10%, 25%]` | 龙头 K 线截图形态验证 |
| **成交额重心** | `D0/D-2 ∈ [1.2, 2.0] → 温和上移` | 截图柱状图视觉验证 |

### 0.3 自动数据与截图交叉验证

| 字段 | API 通道 | 截图通道 | 冲突处理 |
|---|---|---|---|
| 板块成交额 | 精确数值 | 柱状图目测 | 取 API 值，截图验证量级 |

### 0.4 视觉降级机制（API 失败时激活）
若截图中出现 **同色系曲线重叠 / 副图数字模糊 / 暗色主题对比度过低 / 截图分辨率过小**，
**禁止猜测**，必须向用户口述追问对应数值。例如：
> *"成交额柱状图无法精确读取，请口述近 3 日板块成交额（亿元）。"*

### 0.4 关键术语前置定义（防幻觉锚点）

| 术语 | 定义 | 计算口径 |
|---|---|---|
| **Ratio** | 板块吸金强度 | 该板块当日成交额 / 全市场（沪深 或 港股主板）当日成交额 × 100% |
| **Ratio 基准** | A 股单板块历史中位数 3-5%；> 10% 显著吸金；> 20% 高度集中；> 30% 历史峰值区 | — |
| **量比** | 当日成交量 / 过去 5 日均量 | 板块龙头层面计算 |
| **共振度** | 板块内站上 MA20 的个股占比 | 站上 MA20 个股数 / 板块成分股总数 |
| **龙头健康度** | 龙头股的健康标尺 | `近 5 日新高 ≥ 3 次` 且 `换手率 ∈ [10%, 25%]` |
| **首浪突破** | 板块指数有效突破前 60 日箱体上沿，且突破日量比 > 1.5 | — |

## 🧠 核心审计引擎：Certainty Engine

### 1️⃣ 流量持久性 (Persistence)

| 状态 | 触发条件 | 评分 |
|---|---|---|
| 🟢 **确定性** | Ratio ≥ 15% 且近 3 日成交额重心**温和上移**（D-2 < D-1 < D0，且 D0/D-2 ∈ [1.2, 2.0]） | 8-10 |
| 🟡 **观察期** | Ratio ∈ [8%, 15%]，成交额波动但未创新低 | 5-7 |
| 🔴 **阶段性脉冲** | 单日 Ratio 突破 25% 但次日萎缩 ≥ 40%，或 RSI 跳空至 85+ | 1-4 |

### 2️⃣ 空间效率 (Efficiency)

| 状态 | 触发条件 | 评分 |
|---|---|---|
| 🟢 **确定性** | 共振度 ≥ 60% **且** 龙头健康度满足（≥ 2 只龙头同时满足"近 5 日新高 ≥ 3 次 + 换手率 10-25%"） | 8-10 |
| 🟡 **观察期** | 共振度 ∈ [40%, 60%]，龙头存在但换手率偏离健康区间 | 5-7 |
| 🔴 **伪共振** | 仅少数个股涨停，多数缩量跟风或原地踏步；或龙头单日换手 > 30%（派发警报） | 1-4 |

### 3️⃣ 政策锚点 (Strategic)

- 比对板块主线 vs `[当前国家战略主线关键词列表]`
- **完全对齐**（自主可控、卡脖子环节）→ +2 分加权
- **部分对齐**（下游应用、概念叠加）→ +1 分加权
- **无对齐**（纯主题炒作）→ 不加分，且在风控官提醒中明示

## 🛡️ 防追涨协议 (Anti-Chasing Rules)

### 🔴 禁买区（绝对禁止推荐买入）
触发任一条即激活：
- Ratio > 30%（历史峰值区）**且** 板块指数偏离 MA20 > 15%
- 板块单日涨停家数较前 3 日峰值缩减 ≥ 40%（**诱多期信号**）
- 龙头股放量滞涨：成交额创 5 日新高但收盘涨幅 < 1%

### 🟢 黄金区（强烈建议关注）
**首浪突破后缩量回踩 MA10**，且满足：
- 回踩日成交额 ≤ 突破日成交额 × 60%
- 收盘价站稳 MA10 上方
- 共振度未明显下滑（较突破日下降 < 15 个百分点）

### 🟡 中性区
不满足上述两区任一条件 → 维持观察，不做激进推荐
